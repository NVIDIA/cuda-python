37class CUDAError(Exception): 

38 """Raised when a CUDA driver or runtime call fails. 

39  

40 The message names the CUDA error and, when one is known, explains it. A 

41 secondary failure observed while the error was being raised, such as a 

42 failed restoration of the caller's CUDA context, is attached as a note

44 documentation for the guarantees an exception provides.

60class CUDAWarning(RuntimeWarning): 

61 """Warning issued when ``cuda.core`` hits a CUDA error it cannot raise. 

62  

63 ``cuda.core`` raises exceptions for failures in ordinary calls. Some failures 

64 happen where no exception can propagate: while a resource is released by the 

65 garbage collector or by a CUDA callback, including the driver calls that 

66 switch and restore the CUDA context around such a release. Those failures 

67 are reported as this warning instead, and the affected resource may have 

68 leaked. 

69  

70 Filter on this category to make such failures fatal in tests:: 

71  

72 warnings.filterwarnings("error", category=cuda.core.CUDAWarning) 

73  

74 Because the report comes from a destructor, an escalated warning cannot be 

75 raised into user code; it is delivered through :func:`sys.unraisablehook` 

76 (which pytest surfaces as ``PytestUnraisableExceptionWarning``). 

77  

78 .. versionadded:: 1.3.0 

79 """
