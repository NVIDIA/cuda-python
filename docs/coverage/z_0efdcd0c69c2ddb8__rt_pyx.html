5# cython: show_performance_hints=False 

6# 

7# Performance hints are off for this module on purpose. The handle factories 

8# below are declared ``except+ nogil``, and Cython reports each one as an 

9# exception check that "will always require the GIL". For ``except+`` the 

10# GIL is taken only inside the C++ catch handler, so the success path pays 

11# nothing and the hint is noise here. Functions that only return a status 

12# code are declared ``noexcept nogil`` instead, which is what the hint is 

13# really about: without it, every call from a nogil block acquires the GIL 

14# to run PyErr_Occurred(). 

15  

16# This module compiles the C++ under _cpp/rt/ into one shared library. 

17# Consumer modules cimport the functions declared in _rt.pxd. Since there is 

18# only one copy of the C++ code (in this .so), all static and thread-local 

19# state is shared correctly across all consumer modules. 

20# 

21# "rt" is short for runtime: this is cuda.core's runtime support layer 

22# (resource handles, the driver function-pointer table, error reporting and 

23# deferred cleanup). It is unrelated to the CUDA Runtime API (cudart). 

24# 

25# The cdef extern from declarations below satisfy the .pxd declarations directly, 

26# without needing separate wrapper functions. 

27
