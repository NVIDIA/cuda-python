6# 

7# Header-only so both the managed-memory ops and the batched copy path can 

8# cimport it without either module depending on the other. 

9# 

10# Both helpers use field assignment rather than Cython struct literals 

11# (``CUmemLocation(type=..., id=...)``) so this source keeps compiling if a 

12# future generated ``cydriver.pxd`` adds a sibling member to the struct's 

13# anonymous union (e.g. CUDA 13.4's ``localized`` arm): Cython's struct-literal 

14# coercion warns "Not all members given for struct" whenever a call site does 

15# not name every declared member, and cuda_core promotes that warning to a
