73cdef class PinnedMemoryResource(_MemPool): 

74 """ 

75 A host-pinned memory resource managing a stream-ordered memory pool. 

76  

77 Parameters 

78 ---------- 

79 options : PinnedMemoryResourceOptions 

80 Memory resource creation options. 

81  

82 If set to `None`, the memory resource uses the driver's current 

83 stream-ordered memory pool. If no memory 

84 pool is set as current, the driver's default memory pool 

85 is used. 

86  

87 If not set to `None`, a new memory pool is created, which is owned by 

88 the memory resource. 

89  

90 When using an existing (current or default) memory pool, the returned 

91 host-pinned memory resource does not own the pool (`is_handle_owned` is 

92 `False`), and closing the resource has no effect. 

93  

94 Notes 

95 ----- 

96 The device associated with ``stream`` must support host memory pools. If 

97 ``numa_id`` is set or derived for IPC, it must support host NUMA memory pools. 

98 You can query these capabilities through 

99 ``Device.properties.host_memory_pools_supported`` and 

100 ``Device.properties.host_numa_memory_pools_supported``. If the required pool 

101 is unsupported and stream-ordered allocation is not needed, use 

102 :class:`LegacyPinnedMemoryResource`. 

103  

104 The driver makes a host memory pool accessible only from the host by 

105 default, so the resource grants the device that is current when it is 

106 created read and write access to the pool. Kernels on other devices cannot 

107 access its buffers. Without options, the grant applies to the driver's 

108 current pool, which the whole process shares. 

109  

110 To create an IPC-Enabled memory resource (MR) that is capable of sharing 

111 allocations between processes, specify ``ipc_enabled=True`` in the initializer 

112 option. When IPC is enabled and ``numa_id`` is not specified, the NUMA node 

113 is automatically derived from the current CUDA device's ``host_numa_id`` 

114 attribute, which requires an active CUDA context. If ``numa_id`` is 

115 explicitly set, that value is used regardless of ``ipc_enabled``. 

116  

117 See :class:`DeviceMemoryResource` for more details on IPC usage patterns. 

118 """
