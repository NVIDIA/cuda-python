``cuda-pathfinder`` 1.8.3 Release notes
=======================================

Highlights
----------

* Add support for the Windows CUDA 13 cuSPARSELt DLL name
  ``cusparseLt_13.dll`` so ``load_nvidia_dynamic_lib("cusparseLt")`` can
  recognize cuSPARSELt 0.10.0 wheels while retaining support for the previous
  ``cusparseLt.dll`` name.
  (`PR #2982 <https://github.com/NVIDIA/cuda-python/pull/2982>`_)
