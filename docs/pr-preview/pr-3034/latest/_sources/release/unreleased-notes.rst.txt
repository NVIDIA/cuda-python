CUDA Python unreleased changes
==============================

Known Issues
------------

- Updating from older versions (v12.6.2.post1 and below) via ``pip install -U cuda-python`` might
  not work. Please do a clean re-installation by uninstalling ``pip uninstall -y cuda-python``
  followed by installing ``pip install cuda-python``. (`PR #626 <https://github.com/NVIDIA/cuda-python/pull/626>`__)
