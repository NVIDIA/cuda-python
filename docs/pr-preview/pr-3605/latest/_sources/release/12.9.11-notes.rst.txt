CUDA Python 12.9.11 Release notes
=================================

Included components
-------------------

* `cuda.bindings 12.9.11 <https://github.com/NVIDIA/cuda-python/blob/5d81fc030a3679534b4359541926e0106d75b66e/cuda_bindings_12/docs/source/release/12.9.11-notes.rst>`_
  includes NVML additions, callback and memory safety fixes, and packaging and
  source-build changes. See its release notes for details.

End of Life
-----------

* Python 3.10 support dropped (end of life); the supported range is
  Python 3.11-3.15.

Known issues
------------

* Updating from v12.6.2.post1 and older via ``pip install -U cuda-python`` might
  not work. Uninstall with ``pip uninstall -y cuda-python``, then install the
  CUDA 12 line with ``pip install "cuda-python~=12.9.0"``.
