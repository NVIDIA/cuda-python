``cuda.core`` 1.2.2 Release Notes
=================================

New features
------------

- Added wheels for Python 3.15, including the experimental free-threaded
  build. On Python 3.15, ``cuda.core`` requires ``cuda.bindings`` 12.9.10 or
  newer for CUDA 12, or 13.4.4 or newer for CUDA 13, the first releases with
  Python 3.15 wheels. Python 3.10 remains supported.
