``cuda.core`` 1.2.0 Release Notes
==================================

Fixes and enhancements
----------------------

- Buffer cleanup is now context-safe. A :class:`Buffer` keeps a handle on the
  CUDA context its allocation and deallocation stream depend on, and makes that
  context current while the memory is freed, restoring the thread's prior
  context afterwards. Previously the free could fail and leak the allocation
  whenever no suitable context was current on the releasing thread, which
  notably affected buffers attached to a graph, since those are released from a
  deferred cleanup queue rather than from the code that created them. Failures
  encountered during cleanup are now reported on ``stderr`` instead of being
  discarded, and memory-pool deallocation no longer treats
  ``CUDA_ERROR_INVALID_CONTEXT`` as success.
  (`#2455 <https://github.com/NVIDIA/cuda-python/pull/2455>`__)

- :meth:`Buffer.from_handle` and :meth:`ManagedBuffer.from_handle` accept a new
  keyword-only ``stream`` argument that records the stream to be passed to
  ``MemoryResource.deallocate()`` when the adopted pointer is released. It
  defaults to the calling thread's default stream, so a stream-ordered memory
  resource is no longer handed ``stream=None`` at destruction
  (`#2001 <https://github.com/NVIDIA/cuda-python/issues/2001>`__).
  (`#2455 <https://github.com/NVIDIA/cuda-python/pull/2455>`__)

- Graph node resources are now retained independently across graph clones,
  executable graphs, updates, node deletion, and in-flight launches. Previously,
  modifying a graph definition could release resources still used by an
  existing executable graph. Releasing graph-attached objects could also call
  CUDA from a CUDA-invoked callback, where CUDA API calls are prohibited; these
  objects are now released from a safe context.
  (`#2357 <https://github.com/NVIDIA/cuda-python/pull/2357>`__,
  `#2371 <https://github.com/NVIDIA/cuda-python/pull/2371>`__)

Deprecation Notices
-------------------

- Support for using ``cuda-core`` with Python 3.10 is deprecated and will be
  removed in a future version.  Python 3.10 reaches end of life in October 2026
  per the `CPython support cycle <https://devguide.python.org/versions/>`_.
