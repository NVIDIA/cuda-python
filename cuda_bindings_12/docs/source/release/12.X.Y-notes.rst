``cuda-bindings`` Upcoming CUDA 12 Release Notes
================================================

Unreleased

Breaking Changes
----------------

* CUDA 12 bindings require Python 3.11 or newer. Python versions older than
  3.11 are no longer supported; the supported range is Python 3.11-3.15.

Packaging
---------

* Wheels omit ``.pyx`` implementation sources and ``.in`` generation templates,
  following the packaging policy already used by CUDA 13 bindings. Cython
  declarations and includes (``.pxd`` and ``.pxi``), together with required
  headers, remain available for downstream Cython builds. Source distributions
  retain the sources, templates, and other inputs needed to build the package.
