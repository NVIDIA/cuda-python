``cuda-pathfinder`` 1.9.1 Release notes
=======================================

Highlights
----------

* Find cuDNN installed from the ``nvidia-cudnn-cu13`` Windows Arm64 wheel.
  The wheel places ``cudnn64_9.dll`` in ``nvidia/cudnn/bin``, the same
  directory as the x64 wheel, which ``load_nvidia_dynamic_lib("cudnn")``
  previously searched on x64 only. Windows cuDNN discovery checks the DLL's
  architecture so that an incompatible wheel does not prevent searching
  later installation roots. Conda, ``CUDA_PATH``, and Program Files installs
  remain x64-only on Windows Arm64.
  (`PR #3489 <https://github.com/NVIDIA/cuda-python/pull/3489>`_)
