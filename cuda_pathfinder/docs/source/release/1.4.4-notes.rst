``cuda-pathfinder`` 1.4.4 Release notes
=======================================

Highlights
----------

* Support cusparseLt release 0.9.0 (wheels have new directory structure).
  (`PR #1806 <https://github.com/NVIDIA/cuda-python/pull/1806>`_)

* Updated the Windows DLL search documentation.
  (`PR #1795 <https://github.com/NVIDIA/cuda-python/pull/1795>`_)

  .. note::

     **Correction in 1.9.0:** The 1.4.4 release updated the documentation
     to incorrectly state that Python 3.8+ excludes ``PATH`` from the native
     Windows DLL search. The direct ``LoadLibraryExW(..., 0)`` call normally
     includes ``PATH`` for unpackaged processes, subject to process DLL search
     policy. This was a documentation error; the update did not change DLL
     loading behavior.
     (`Issue #3137 <https://github.com/NVIDIA/cuda-python/issues/3137>`_)
