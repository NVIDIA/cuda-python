``cuda-bindings`` 13.6.0 Release notes
======================================

Behavior changes
----------------

- ``cuda.bindings.utils.check_nvvm_compiler_options()`` now returns ``False`` when libNVVM
  cannot be found. Previously it raised ``cuda.pathfinder.DynamicLibNotFoundError``.
  (`Issue #3565 <https://github.com/NVIDIA/cuda-python/issues/3565>`_)
