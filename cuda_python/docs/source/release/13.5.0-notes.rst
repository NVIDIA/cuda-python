CUDA Python 13.5.0 Release notes
=================================

Highlights
----------

* Python 3.10 support was dropped (end of life). Python 3.15 is now officially supported.
* ``cuda-python`` 13.5.0 pulls in ``cuda-bindings`` 13.5.0. See the
  ``cuda-bindings`` 13.5.0 release notes for the new CTK 13.5 APIs and other changes.

Known issues
------------

* Updating from older versions (v12.6.2.post1 and below) via ``pip install -U cuda-python`` might not work. Please do a clean re-installation by uninstalling ``pip uninstall -y cuda-python`` followed by installing ``pip install cuda-python``.
